# 🤖 سیستم پاسخگویی هوشمند فارسی مبتنی بر RAG

یک سیستم پاسخگویی فارسی مبتنی بر RAG برای **پشتیبانی مشتریان**، ساخته‌شده با LangChain، FAISS و مدل‌های زبانی محلی.

---

## ✨ ویژگی‌ها

- 🔍 **جستجوی معنایی فارسی** بین اسناد با استفاده از مدل embedding بومی `Tooka-SBERT-V2-Large`
- 📄 **Chunking ساختاریافته** بر اساس فرمت Markdown
- 🗂️ **پایگاه داده برداری محلی** با FAISS
- 🧠 **LLM قابل اجرا به صورت محلی** با مدل `DeepSeek-R1-Distill-Llama-8B-abliterated` و API Ollama
- 🎭 **سیستم پرامپت قابل تنظیم** برای تغییر لحن و نوع پاسخگویی به مشتریان
- 🇮🇷 **پاسخگویی به زبان فارسی**
- 🛡️ **محدودسازی به context** برای جلوگیری از سوگیری و توهم‌زایی

---

## 📋 پیش‌نیازها

- 🐍 **پایتون 3.11**
- 🦙 **Ollama** ([راهنمای نصب](https://ollama.com/download))
- 🧠 **مدل DeepSeek-R1-Distill-Llama-8B-abliterated**
- 📚 **مدل Tooka-SBERT-V2-Large**
- 💻 **سیستم مورد نیاز** برای اجرای مدل DeepSeek (حداقل ۸ گیگابایت RAM، ترجیحاً GPU)
